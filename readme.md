# YouTube Chatbot

## Project Overview

This project is a locally hosted YouTube chatbot. It operates using [node.js](https://nodejs.org/en) and the [YouTube Data API v3](https://console.cloud.google.com/apis/library/youtube.googleapis.com). With this you can create a custom YouTube chatbot that can do whatever you program it to do (or just use the presets that I made for my own livestreams)

I have not worked on this in like 6 months, but after looking at it again when preparing to upload it to GitHub, I realized that I would like to work on it again. I will probably revisit this project eventually as there is a lot I could do with it.

## Features
- Chat commands which can be customized by writing JavaScript yourself or editing the few things in the [config.json](/config.example.json)
- Watchtime tracking
- Viewer leveling system
- Point earning
- A leaderboard for watchtime, points and experience
- 2 built in games for users to spend their points on
- A small shop where viewers can spend their points
    - The tts does not work all the time, so I would reccomend leaving it disabled until future updates

## Setup
### Bot Setup
1. Clone the repository
2. Make sure [node.js](https://nodejs.org/en) is installed
3. [Set up Google Cloud Console](#google-cloud-console-setup)
4. Configure your chatbot using the [example config file](/config.example.json), and when you are done, rename it to `config.json`
5. Install the projects dependancies by running `npm install`
6. (Optional) Customize the chat commands by modifying or adding cases to the large switch statement in the processQueue method of the ChatBot class in [youtubeService.js](/youtubeService.js) (I would only reccomend doing this if you know what you are doing!)
7. Start the server using `npm start`, and head to `http://localhost:3000` to authenticate the channel and bot accounts, and start the bot
8. You can also add the live chat as an element in OBS by creating a browser source and setting the url to `http://localhost:3001` (this is the URL that the overlay elements are hosted on)

### Google Cloud Console Setup
#### Create your Google Cloud project
1. Go to the [Google Cloud Console](https://console.cloud.google.com/)
2. Sign in and select "Create or select a project" and then press "New project"
3. Give it a name (eg. YouTube Chatbot) and hit create, and select it after it creates
#### Enable the YouTube API
1. From the left sidebar, select APIs & Services
2. Press the "Enable APIs and services" button at the top
3. Search "youtube" and select "YouTube Data API v3", and press enable
#### Configure OAuth
1. While on the APIs & Services screen, select "OAuth consent screen" from the sidebar
2. Select "Get started"
3. For "App information" put in a name for your "app" and a support email
4. For "Audience" select external (unless using a google workspace account)
5. For "Contact Information" put in your email
6. For "Finish" select agree, and then hit create
7. Go to "Clients" in the sidebar and hit "Create Client"
8. Select "Web applicaton" as the type and give it a name
9. Under "Authorized redirect URIs", add these two URIs: `http://localhost:3000/callback` and `http://localhost:3000/bot-callback`, and press create
10. Copy the "Client ID" and "Client Secret" into their respective spots in the [example config file](/config.example.json)
11. Finally, go to "Audience" in the side bar and under "Test Users" add the email of the channel that will be livestreaming, and the email of the channel that the bot will be using
12. Continue with the rest of the [bot setup](#bot-setup)
